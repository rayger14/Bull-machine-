### The bounded pattern finding

Using the already-defined hourly geometry, upside expansions were5/5 positive
(+$6,450.09); downside expansions were7wins/6losses across13 (+$3,707.38).
That suggests analyzing the two setup families separately. It does **not** justify
removing downside LC, which remained net positive here. Moreover, the earlier
[pattern table](lc_pattern_table_2026_09_14.md) records upside expansions losing
both April examples. The direction split is not a stable validated tuning rule.

### Exact interface failure

`source_packet.evidence_catalog` exposes atomic `E####` IDs;
`source_packet.group_catalog` exposes timeframe/context/curriculum groups.
The schema says only “known evidence IDs”; `grade_context_choice` accepts only
the second catalog. LC1–LC4 cited21/27/29/26 distinct disallowed-but-visible IDs;
none of their cited IDs was absent from both catalogs. Text lengths remained
within1200 characters. ID existence does not itself establish claim entailment.

All four terminal records preserve `specialist_invalid/invalid_assessment`.
The job-level status is `invalid_transport` because a transparently non-invoked,
transport-false reviewer sentinel is required by storage; this must not be
misreported as failed specialist byte delivery or four completed critic reviews.
The status field `reviewed_grades=4` counts locked grades, not semantic reviews.
