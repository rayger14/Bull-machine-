## Stage 1: source-only independent review

Use the exact twelve source packets already exported, never replacement cases.
A fresh packet-only reviewer sees no developer history, policy decisions or
future outcomes. Process cases in chronological cutoff order; save each answer
before reading the next. One reviewer is a source-fidelity audit, not twelve
independent predictive trials or human trader certification. Model session usage
is still usage; no separate external API calls are launched.

For readability, a deterministic compact view uses short citation aliases,
tabular OHLCV and explicit availability/status. Preserve every source observation
and all non-observation metadata; bind the exact original packet and alias map.
No selected pivots, evidence classifications, action labels or outcomes are added.
The full packet remains the source of truth. Translation restores original IDs
and uses the frozen annotation validator. Schema validity is not semantic truth.

Review location, uncertain phase, recovery vs parent escape, support reaction,
confirmed minute sequence, invalidation, room and action. Treat the numerical
48h/72h/60min, pivot, 2R and volume rules as project hypotheses, not authenticated
trader formulas. A pivot box alone is never confirmed accumulation. Cite facts;
mark missing or insufficient evidence unknown/disputed. Do not force agreement.

Root reconciles every annotation against the frozen decision and the raw packet,
records disagreements and unresolved material issues, and binds that review to
the exact source receipt/policy/code/annotations. Unresolved source, causality or
implementation defects BLOCK economics. Reasonable differences in judgment can
be documented without claiming the strategy is validated. A later hypothesis
change requires a separately versioned study, not retroactive annotation edits.

frozen protocol, original stop/fixed2R/7d. No tuning or adaptive management.

unknown and boundary fixtures. It may not silently reset unknown occupancy.

than launch an unbounded run or fabricate accounting.
