# Frozen four-case agent entry mini-study

Approved user intent: assess code-aware multi-timeframe entry judgment, freeze the answer before revealing subsequent prices, and start small. Research-only; no live orders, production changes, optimization or autonomous management.

## Selection before outcomes

Use the previously audited June10–20,2026 historical artifacts. Hourly: earliest LC structural-pass/non-emitted candidate, and earliest LC emitted candidate, after the first24 replay hours. Minute: earliest chronological frozen sweep/reclaim candidate on each selected hourly UTC decision date, excluding already selected event IDs if the dates coincide; no available distinct event blocks the study. Sort ties by event ID. Exactly two hourly and two distinct minute cases. This intentionally covers hourly emission strata, is not a representative trade sample, and retains the prior examined emitted LC case. No profit-based selection, replacement or extra cases. Selection-stratum labels, original outcome-bearing IDs/filenames and baseline flags stay in a separate hashed manifest, not the agent packet.

Hourly prices/context come only from the V23 hourly stream; minute prices/context only from its saved Binance minute stream. No cross-venue splice. Native replay features are current-code historical calculations, not certified historical live inputs. Fixed4H/N3 parents use existing same-stream ledgers, and recorded availability must precede first-sweep time. Parent coverage/cold starts and missing derivatives/provenance remain disclosed.

## Blinded agent packet

One fresh assessor invocation receives all four packets plus compact, exact relevant code excerpts and rule definitions, but no future bars, pass/fail labels, engine emission flags, baseline masks, simulated entries/fills, outcomes or answers. Input uses completed bars only: last12 local candles (hourly for hourly cases, minute for minute), last6 completed4H candles and last3 completed daily candles; no developing HTF candle. Include current/prior selected numeric features for hourly, child geometry for minute, as-of parent versions and lifecycle evidence. No opaque whole replay manifests carrying historical performance summaries. Exclude comments/docstrings from code excerpts where they contain performance claims.

Agent returns accept/reject/insufficient_evidence per case, evidence-cited thesis and gate interpretation, relevant parent/child structure, a falsifiable expected path, and explicit invalidation. It assesses the registered immediate-entry plan, not a newly invented limit entry. It may state contextual weaknesses in gates without changing their implementation. Opinions are conditional on the supplied research data; unavailable macro/derivatives must not be invented. Missing live receipt certification alone does not prohibit a conditional research opinion, but never becomes trading authority. The short context may legitimately be insufficient. No critic, retries, prompt tuning or forced acceptance balance.

## Fixed hypothetical outcome measurement

All candidates are independently measured regardless of agent decision. Long entry at the same-stream bar OPEN at the decision timestamp (next bar after the completed setup), zero added decision delay. Hourly stop = decision close minus2.7×the native replay ATR; minute stop = frozen sweep_low×0.9985. Target = actual entry +2×(actual entry-stop), a conditional formula frozen before outcomes. Hourly horizon24hours; minute240minutes. If stop>=entry, retain invalid-plan status and no invented trade. Stops/targets are benchmark brackets, not claims of validated structural invalidation or objectives.

“Decision close” means the immediately preceding completed setup candle's close; every supplied feature/ATR must have recorded replay availability by the decision boundary. This is computational availability, not authenticated live receipt. Quantity=$50,000/entry_price. Measure bars in [entry_time,entry_time+horizon), including entry; excursions continue through that full window even after hypothetical bracket exit and must be labeled as such. The deadline candle contributes only its OPEN to the horizon return/terminal exit.

Entry-bar touches count. Stop gaps fill at min(stop,baropen); favorable target gaps conservatively fill at target. If both touched within one OHLC bar, report ambiguity and use stop-first for the explicitly conservative diagnostic. Otherwise first barrier wins. Deadline exit uses the horizon bar OPEN, before inspecting that bar's high/low. Missing bars/tails block the study; no truncation or forced terminal close. Entry fills assume instantaneous decision, omit model latency and are not certified obtainable fills.

Record full-horizon favorable/adverse excursions, horizon-open return and first-barrier outcome for every candidate. Fixed$50,000 notional, $60/12bps round-trip modeled cost, no starting-equity/margin/compounding/funding/impact assumption. Report per-case initial risk and gross/cost/net diagnostic PnL. No continuous equity curve, Sharpe, significance, independence claim or headline strategy return from four overlapping BTC cases. An accepted/rejected case subtotal is not a portfolio replay or causal avoided-loss estimate.

## Comparators and interpretation

Hourly baseline: saved native emitted versus non-emitted signal (not necessarily executed entry). Minute baseline: existing frozen detector emits both selected events (not the live hourly engine). Mechanical baseline: hourly finite volume>=3, strict RSI>65 or<35, BB<=.06, chop<=.50, plus existing H2 previous-width condition; minute existing H3 fixed-parent policy. Also disclose hourly H3 separately as a restrictive research subtype, not silently make it a universal gate. Agent receives the same underlying data used by these controls; no fitted weights.

Compare decisions and per-case outcomes, including agent rejects that would have won. Retain insufficiency separately; do not call it a successful rejection. Distinguish objective/invalidation benchmark from narrative conditions not formally scoreable. This pilot can expose disagreement and test the workflow; it cannot establish agent superiority. Same-evidence richer deterministic alternatives, matched inference budgets, forward shadow data and execution-aware portfolio replay remain future requirements.

Invalid-plan cases remain in decision counts but contribute no bracket PnL; label them separately. Subtotals include only valid hypothetical positions accepted by the specified arm; costs charged once per position. Report rejected and insufficient-evidence candidate outcomes separately. Missing/nonfinite mechanical inputs produce unknown rather than silently passing a skipped gate; this stricter research comparator is not a native gate-parity claim. H2 and H3 use existing source-hashed evaluator definitions, with unknown retained.
