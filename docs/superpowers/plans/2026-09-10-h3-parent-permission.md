# H3 Parent Permission Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Annotate fixed hourly/minute child events with causal parent permission, without changing selection or execution.

**Architecture:** One pure sidecar consumes the existing immutable parent ledger and explicit frozen event witnesses. One batch helper requires all four parent configurations and reports counts only.

**Tech Stack:** Python 3.9, pandas, pytest, existing replay-clock digest and parent binding.

**Spec:** `docs/superpowers/specs/2026-09-10-h3-parent-permission-design.md`

## Global Constraints

- No production `engine/`, `bin/`, or `configs/` changes, live changes, optimizer, public push, entry/exit simulation, or performance claim.
- Preserve all 17 native archetypes and unrelated graph outputs; work on the current research branch in place.
- Exact same instrument/data stream only; no silent V23/hourly-to-minute-venue pairing.
- Parent input cap remains 2,048 contiguous hours; no arbitrary history chunking.
- Every result remains `certified=False`; permission is not source-receipt authentication or a profitable-strategy finding.
- All four parent configurations are reported independently; no winner selection.
