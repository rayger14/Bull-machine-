1. THE MIRROR (EXACT inversion of trend_continuation_door.py / UnifiedArchetypeV2._m2,
   m2_mode='broad'; NO NEW PARAMETERS — every magnitude imported from
   unified_archetype_v2.py, none redefined). LONG spec -> SHORT spec, term by term:
--------------------------------------------------------------------
   REGIME R0 (permission; mirror of long "not-markdown"):
     long : stables_rot_rising==0 AND (close> ema200 OR state != BROKEN_DOWN)
     SHORT: stables_rot_rising==0 AND (close< ema200 OR state != BROKEN_UP)
     NOTE: build_base_sensors sets stables_rot_rising=0 on EVERY asset (price-only door),
     so the stables term is INERT on all families; R0 reduces to the not-markup clause.

   TRIGGER + ENTRY (breakdown-retest = mirror of the breakout-retest):
     T1  eye_dir[i]=='bear'            (standing bias set bear only by a confirmed DOWN-break)
     T2  eye_state[i] in {MODEL_FORMING(inert), IN_RANGE, MANIPULATION}  (non-extension:
         NOT CONFIRMED_BREAK/TRENDING -> we enter the PULLBACK, never the extension)
     T3  a bear CONFIRMED_BREAK (eye_state==CONFIRMED_BREAK AND eye_dir=='bear') within
         trailing M2_SOS_WIN bars -> break_level = range_LOWER_1d at that break bar
         (mirror of range_upper). Else the setup does not exist (window expiry = skip).
     T4  close[i] <= break_level        (the down-break was NOT given back = HOLD below)
     T5  high[i] >= break_level - RTZ_ATR*ATR   (pulled back UP INTO the retest zone)
     ENTRY SHORT at close[i].

   STOP:  created_high = max(high) over trailing LPS_LOOKBACK bars (the pullback leg);
          stop = created_high + STOP_BUF_ATR*ATR14(entry).   (mirror of created_low - buf)

   MANAGE (two exit variants; identical entries+stops):
     'struct' (HEADLINE) = TP1 40% at struct_range_LOW (else swing_low_50, else entry-1R;
         must clear <= entry - MIN_TP1_R*R) -> stop to BREAKEVEN -> runner 60% to the
         DOWNSIDE MEASURED MOVE struct_range_low - (range_high-range_low), floored (i.e.
         capped further-down) at entry-2R via tt = min(entry-2R, measured).
     'naive' = plain 1R/2R/3R equal thirds to the downside.
     max_hold = MAX_HOLD bars. HEADLINE = struct / flat (rmult=1.0, conviction OFF).

   SIZE (reported, NOT headline): base 1%; CONVICTION_MULT if (fib_time_confluence>0)
     OR (bojan zone active). FLAG: the mirror's conviction sensor is NOT inverted
     (bojan_LOW is used, bojan_HIGH not built). Immaterial to the verdict: the headline
     is struct/flat rmult=1.0, immune to fib/bojan (exactly as the long headline).

   DEDUP: no re-entry within DEDUP_K bars of the last entry.

   IMPORTED PARAMS (identical to the long door; NONE new):
     M2_SOS_WIN=360  LPS_LOOKBACK=48  RTZ_ATR=0.5  STOP_BUF_ATR=0.25  DEDUP_K=3
     CONVICTION_MULT=1.5  MAX_HOLD=168  MIN_TP1_R=0.5  HTF_N=5 (weekly struct range)
