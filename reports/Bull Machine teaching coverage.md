# Bull Machine teaching coverage

**Outcome:** Bull Machine already contains extensive teachings about context, pre-existing levels and zones, ordered events, entries, invalidation, management, and multi-timeframe structure within structure. It does **not** contain a complete, authenticated original curriculum for every named trader, a source-faithful executable contract for all 17 archetypes, or evidence that those concepts survive the active entry path. The dominant near-term problem is not a lack of trading vocabulary: rich objects and sequences are often reduced to flags, scalars, same-bar conditions, or optional gates before a named archetype emits. The corpus is strong enough to reconcile reusable machinery and write **one source-specific contract**, then trace it through current code before changing anything. It is not strong enough to certify all 17 as teacher-faithful or profitable. R1 and R3 remain proposals, R2 remains parked, and this audit ran no tests, backtests, scoring, code changes, or model-trader campaign.

## Concept discussion is broad; executable and active fidelity are not

Four different questions must stay separate: **D** = discussed in compiled material; **O** = authenticated in inspected originals; **E** = sufficiently specified to execute some version; **C** = faithfully carried by the current named-17 entry path.

## One source-faithful trace is ready; an all-17 repair is not

The finite next step is to select **one setup and a bounded set of exact original posts**, record claim-level source versions and chart examples, and freeze: parent/range anchors; pre-existing level or zone ID; origin, confirmation and availability clocks; ordered transitions; entry and cancellation; zone life/mitigation/expiry; invalidation; destination; conditional management; and positive plus failure examples. Then trace existing detectors, feature rows, gates, runner entry and exit consumption against that contract before modifying code. The identities and candidate locators are now recorded; the remaining source requirement is lawful readable original text, charts, threads or transcripts, not asking the user to find the profiles again.

This is enough evidence to begin **reconciliation and one contract**, not to launch an all-17 rewrite, revive R2, assume R1/R3 are implemented, or claim profitability. The practical distinction is now clear: missing original archives and exact definitions are knowledge/provenance gaps; lost IDs, clocks, lifecycles and conditional management are implementation gaps; profitability remains a separate experiment after fidelity is demonstrated.
