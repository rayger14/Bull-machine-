# Original Teachings Bound Wyckoff Recognition

**Original and author-attributed teachings can ground a 12-case raw-candle exam by defining relationships among range location, price-volume behavior, confirmation, and invalidation—not by supplying machine thresholds.** The strongest test asks whether candles are consistent with an event, whether the surrounding phase supports that interpretation, and whether directional permission has actually emerged. It should contain four genuine structures, four close lookalikes, and four cases whose evidence remains unresolved. A sweep alone is not a spring or upthrust; later testing, strength or weakness, and the parent range matter. Disagreement across timeframes or sources must survive in the answer key rather than be collapsed into a scalar verdict. The harness has not yet been built or run, so this is a source-grounded exam design, not a recognition result.

## Historical teaching supplies the backbone, not constants

An inherited prior-reading receipt for Richard Wyckoff’s 1910 primary text supports accumulation, markup, distribution, price-volume reading, patience, and waiting for range evidence when direction is uncertain; the archived primary was **not freshly read for the current source notes**, and it does not authenticate the later A–E, spring/test/SOS vocabulary ([public-domain scan](https://archive.org/details/studiesintaperea00wyckrich)). A modern Wyckoff-school tutorial supplies that later qualitative grammar: springs and UTADs are optional, tests should show reduced supply or demand, and SOS/LPS or SOW/LPSY behavior helps resolve the range ([Wyckoff Analytics](https://www.wyckoffanalytics.com/wyckoff-method/)). Contemporary trader material adds useful cautions: range-edge context precedes a wick, close/hold behavior differs from a sweep, a retest can fail, and HTF location and LTF execution have distinct roles. These sources ground contrasts only; they do not establish penetration percentages, volume ratios, candle counts, ATR buffers, profitability, or predictive edge.

## Twelve cases separate structures from resemblance

| Class | Four approved planned raw-candle cases |
|---|---|
| Genuine | **Spring accumulation**; **no-spring accumulation**; **upthrust distribution**; **no-upthrust distribution**. |
| Near-miss | **Missing range**; **missing recovery**; **failed test**; **invalidated parent**. |
| Ambiguous | **Climax versus continuation**; **developing range**; **local rebound versus range escape**; **conflicting timeframes**. |

Every card should expose only candles available at its adjudication cutoff, plus parent-range identity and timeframe, candidate event, relevant closes, spread/volume comparisons, and missing fields. The key should score **structural event, phase interpretation, and directional permission separately**. Competing readings should be recorded with their evidence and provenance; neither HTF nor LTF receives automatic precedence, and future candles must not settle an earlier ambiguity.

## Conclusion

The exam’s real value is epistemic discipline: it tests whether recognition preserves context, sequence, availability, and uncertainty before any detector is judged. A passing future harness would demonstrate bounded semantic coverage of these 12 frozen contrasts—not author intent, exhaustive Wyckoff fidelity, trading edge, or live readiness.
